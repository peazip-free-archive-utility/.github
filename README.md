## Archiver Overview

PeaZip is a free, open-source archive manager built for versatility. It reads and extracts more than two hundred file types, from everyday ZIP and 7z to obscure legacy and Unix formats, making it a true universal opener.

Security is a core focus. PeaZip supports strong encryption with multiple cipher options, encrypted filename headers, and two-factor authentication using keyfiles. A secure deletion tool wipes sensitive originals so they cannot be recovered.

The interface adds practical productivity touches such as a bookmark system, batch conversion between archive types, and a file manager for browsing and comparing directories. Being portable and cross-platform, it runs consistently on Windows, Linux, and macOS.

## Getting Started Playbook

Download PeaZip in installer or portable form, then launch its file-manager-style window. Optional shell integration adds archive commands to your right-click menu for quicker access.

To build a protected archive, add your files, pick a format such as 7z or PEA, and set an encryption cipher with a password or keyfile. Confirm, and PeaZip produces a locked, ready-to-share bundle.
